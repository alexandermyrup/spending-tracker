# Spending Tracker — UI Audit
**Date:** 2026-04-18
**Scope:** Dashboard (Monthly, Weekly, Yearly), Transactions, Budgets, Categories
**Method:** Chrome DevTools visual + JS probes against live GitHub Pages build. Mobile inspected briefly (per-user request to ignore).

---

## Anti-Patterns Verdict
**Pass.** This does not look AI-generated. Restrained slate + accent palette, no gradient text, no glassmorphism, no generic card-grid bloat. Typography hierarchy is strong and the hero framing ("Over budget by 8.242 kr.") is a confident, narrative choice. One mild AI-slop tell: the hero card's tinted pastel background + heavy headline + KPI grid layout is a common AI template, but it's executed well and earns its space. Overall the design reads as a thoughtful, editorial financial tool, not a ChatGPT template.

## Detailed Findings

### CRITICAL

**C1. Muted text fails WCAG AA contrast (77 uses)**
- **Location:** Global. `color: rgb(148,163,184)` (slate-400) used on `rgb(255,255,255)` backgrounds.
- **Contrast:** 2.56:1 (AA requires 4.5:1 for text <18pt, 3:1 for ≥18pt bold)
- **Impact:** Affects diagnosis body copy ("Last mo: -3.527 kr.", "3-mo avg: -262 kr."), the "/ 6.007 kr." secondary target, and helper text across all views. Unreadable for low-vision users and in bright sunlight.
- **Standard:** WCAG 2.1 AA 1.4.3
- **Fix:** Replace slate-400 with slate-500 (`#64748B`, 4.76:1) for body text <18pt; reserve slate-400 only for decorative elements.
- **Command:** `/normalize` (or `/colorize` then manual token mapping)

**C2. 2907 of 2913 form inputs have no accessible name**
- **Location:** Budgets grid (12 months × ~40 categories of number inputs), Transactions table (Type dropdowns, Category selectors).
- **Impact:** Screen readers announce these as "edit, 4778" with no row/column context. Non-usable with AT. Also affects voice control.
- **Standard:** WCAG 2.1 A 4.1.2, 3.3.2
- **Fix:** Add `aria-label` combining category + month (e.g. `aria-label="SU budget, January 2026"`). Easiest: template each cell with `aria-label="${category} ${month} ${year}"`.
- **Command:** `/harden`

**C3. "Rename" buttons 64x22px — far below touch target minimum**
- **Location:** Categories page, every row (40+ instances).
- **Impact:** Unusable on touch devices, difficult to click precisely with a mouse. Fails WCAG 2.5.5 (44x44 target).
- **Standard:** WCAG 2.1 AAA 2.5.5, AA 2.5.8 (24x24 minimum)
- **Fix:** Expand to at least 40px tall, ideally full-row click with icon affordance.
- **Command:** `/polish` or `/arrange`

### HIGH

**H1. green-600 (`rgb(22,163,74)`) fails AA for normal text (3.30:1)**
- **Location:** Income numbers, "3-mo avg" badges, positive deltas like "+69 kr." on Weekly.
- **Impact:** Most green usages are on large bold numbers (passes 3:1 large-text rule), but 11-14px body green text fails AA.
- **Fix:** Use green-700 (`#15803D`, 4.54:1) for body text. Keep green-600 for ≥18pt bold only.
- **Command:** `/normalize`

**H2. Export / Import JSON buttons 94x38 — below 44px touch minimum**
- **Location:** Top-right toolbar.
- **Impact:** Destructive-adjacent actions (Import replaces data) should have comfortable targets.
- **Fix:** Height 38 → 44.
- **Command:** `/polish`

**H3. Heading order anomaly: `<h2>Categories</h2>` precedes the only `<h1>`**
- **Location:** Sidebar nav appears to use `<h2>` or similar for group labels. The only H1 is "Spending Tracker" in the brand block but sidebar navigation inserts an H2 before it in DOM order.
- **Impact:** Screen reader heading-nav jumps in wrong order.
- **Standard:** WCAG 2.1 AA 1.3.1
- **Fix:** Sidebar nav labels should be `<span>` inside `<a>`, not headings. Confirm H1 is first heading in the document.
- **Command:** `/harden`

**H4. Missing `<header>`/`<footer>` landmarks**
- **Location:** Top toolbar (version + Export/Import) has no landmark; no footer exists.
- **Impact:** Skip-nav and landmark navigation incomplete.
- **Fix:** Wrap top toolbar in `<header role="banner">`. Add minimal footer with `<footer role="contentinfo">`.
- **Command:** `/harden`

**H5. Sidebar nav items 215x40 — below 44 height**
- **Location:** Dashboard / Transactions / Budgets / Categories nav links.
- **Impact:** Borderline — width is huge (easy click), height 40 is 4px short. Primary navigation should exceed AA target.
- **Fix:** Padding-y bump to reach 44.
- **Command:** `/polish`

### MEDIUM

**M1. Burn-down chart missing axis labels**
- **Location:** Monthly Dashboard.
- **Impact:** Y-axis shows "5.000 / 10.000" with no unit; X-axis "1 6 11 16 21 26 31" with no label. Requires inference.
- **Fix:** Add "kr." suffix on Y, "Day of month" label on X.
- **Command:** `/clarify`

**M2. Budget grid lacks group visual separation**
- **Location:** Budgets page.
- **Impact:** INCOME / SAVINGS / FIXED COSTS groups are visually uniform — scanning is hard. The grid reads as 40 identical rows.
- **Fix:** Add subtle group-header rows with slightly darker tint; alternate zebra rows within groups.
- **Command:** `/arrange` or `/extract`

**M3. Per-category cards on Monthly use identical card style — visual monotony**
- **Location:** "Per category, last 6 months" grid.
- **Impact:** 22 identical bar-chart cards at identical sizes. The eye can't quickly find the overspending ones.
- **Fix:** Scale cards by overspend magnitude, or sort overbudget to top with visual emphasis. Consider heat-mapping the card backgrounds.
- **Command:** `/arrange` or `/distill`

**M4. Transactions "row action" icons (scissor, X) lack labels**
- **Location:** Far-right of every transaction row.
- **Impact:** Hover tooltip implied but not visible; irreversible delete (X) has no confirmation cue.
- **Fix:** Add `aria-label` and visible tooltip. Consider destructive-action confirmation state.
- **Command:** `/harden` + `/clarify`

**M5. Category Manager — every row renders a separate "Rename" button**
- **Location:** Categories page.
- **Impact:** Visually noisy, repeated affordance eats horizontal rhythm. Consider pencil icon + full-row hover state.
- **Fix:** Replace text button with icon button (pencil) revealed on row hover.
- **Command:** `/distill` + `/polish`

**M6. "17 merchants with conflicting categories" warning — disclosure unclear**
- **Location:** Transactions top banner.
- **Impact:** The `▶` indicates expandable content, but the full affordance is buried. At a glance looks like a passive alert.
- **Fix:** Explicit "Review →" button or native `<details>` with clearer expansion cue.
- **Command:** `/clarify`

**M7. Checkboxes and form controls use browser defaults (`Exclude covered`)**
- **Location:** Top filter bar across Dashboard views.
- **Impact:** OS-native checkbox clashes with the otherwise-customized blue accent palette. Minor but breaks visual consistency.
- **Fix:** Style via `accent-color: var(--primary)` or custom checkbox. (One-line CSS fix.)
- **Command:** `/polish`

## Patterns & Systemic Issues

1. **Muted-text palette is too light** — slate-400 is the go-to "secondary text" color but fails AA everywhere except decorative/large-bold uses. This is the single biggest fix: one token change propagates to 77+ instances.
2. **Form inputs lack labels at scale** — 99.8% of inputs unlabeled. Likely one template missing `aria-label`. Single-pattern fix unlocks whole-app accessibility.
3. **Touch targets under 44px in 56 places** — Categories "Rename" is the worst offender. Adopting a minimum `min-height: 44px` utility class would catch most.
4. **Visual monotony in card grids** — "Per category" (22 cards), "Budget grid" (40 rows), Categories list. All three use identical row/card style with no visual weighting. Opportunity for data-driven emphasis.

---

## Positive Findings

- **Strong narrative framing.** "Over budget by 8.242 kr." is a confident, opinionated headline — most finance tools would say "Monthly Summary". Keep this.
- **Hero metric colored background** signals state without shouting. Mild pink-red when over budget, likely green-tinted when under.
- **Typography hierarchy** is crisp: 48px+ hero numbers, 11px all-caps micro-labels, clear steps between. No wasted weights.
- **Information architecture is tight.** 4 nav items map to 4 distinct jobs. No drawer-within-drawer bloat.
- **The narrative "At this pace, Mar 2026: 3.678 kr. (saving 2.329 kr.)"** on Weekly is the kind of copy that justifies the app's existence. Replicate elsewhere.
- **Skip-to-main-content link exists.** Rare and nice.
- **Mobile renders without horizontal overflow** at 390px — responsive skeleton works.
